# Philippine place search

`philippine-places.json` reuses the Bulletin's derived GeoNames Philippine
administrative place index, licensed CC BY 4.0.

Source: https://www.geonames.org/
License: https://creativecommons.org/licenses/by/4.0/

The file contains regions, cities, and municipalities, not street addresses.
See `apps/quakestrikeph-bulletin/public/assets/accounts/README.md` for source
coverage and the documented refresh command. Refresh both copies together.
