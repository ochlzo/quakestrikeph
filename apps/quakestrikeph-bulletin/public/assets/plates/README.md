# Map loading placeholder

`relief-map.webp` is a screenshot of the Bulletin's current default desktop
basemap, captured on 2026-10-02 from the local production build. It uses the
same OpenFreeMap Liberty style, label cleanup, supplemental GeoNames labels,
and ocean color (`#74A9D9`) as `src/components/MapPanel.tsx`.

The capture uses center `[123.3, 10.8]`, zoom `5.55`, pitch `0`, and bearing
`0`, in an 895 × 649 CSS-pixel map at device scale 2. Earthquake data and
interface overlays are excluded. The 1790 × 1298 screenshot is encoded as
WebP at quality 85. Regenerate when the default basemap appearance changes.
